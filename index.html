The easiest way to start real-time booking with Calendly (free)
  1. Go to calendly.com and sign up — the free plan is enough to start (1 event type, unlimited bookings).
  2. Click "Create" → "1-on-1" event, then set your event name (e.g. "30-Min Consultation"), duration, and location (Zoom/Google Meet/phone).
  3. Under Availability, connect your Google/Outlook calendar so Calendly automatically blocks times you're already busy — this is what prevents double-booking.
  4. Once your event is created, click Share on that event.
  5. Pick "Add to Website" → "Inline Embed" → copy the code shown.
  6. Come back here, switch "How should visitors book?" above to Calendly / External Calendar Embed, and paste that code into the box.

That's it — once embedded, visitors see your real calendar and book instantly, no manual confirmation needed on your end.
